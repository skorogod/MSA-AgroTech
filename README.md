# МСА «АгроТех Х» — проектная работа

Учебный проект по микросервисной архитектуре (Яндекс Практикум).

Компания «АгроТех Х» занимается растениеводством и свиноводством: 150 тепличных комплексов, свой парк техники, разнородный IT-ландшафт. Задача проекта — спроектировать MVP платформы мониторинга скота: видеоаналитика поведения животных, управление кормушками и поилками, оповещение сотрудников. Платформа строится по схеме «центральная система — агенты на фермах» и должна работать даже при отсутствии интернета.

## Как отрисовать диаграммы

```bash
java -jar plantuml.jar -DRELATIVE_INCLUDE="." -tpng -o . Task1/*.puml Task2/*.puml Task3/*.puml Task5/*.puml
```

Флаг `-DRELATIVE_INCLUDE="."` заставляет шаблон брать `templates/C4.puml` локально; без флага он подтянет C4-PlantUML из интернета.
